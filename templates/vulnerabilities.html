Understand common vulnerabilities, their potential impact, and recommended defensive measures.

🗄️

SQL Injection

An attack in which untrusted input interferes with database queries.

Recommended mitigation

Use parameterized queries, validate input, and apply least-privilege database permissions.

🌐

Cross-Site Scripting (XSS)

A vulnerability that can allow untrusted scripts to execute in another user's browser.

Recommended mitigation

Apply context-aware output encoding, sanitize HTML when appropriate, and use a suitable Content Security Policy.

🔑

Broken Access Control

Occurs when an application does not properly enforce what an authenticated user is allowed to access.

Recommended mitigation

Enforce authorization on the server for every protected resource and test access-control rules.

⚙️

Security Misconfiguration

Insecure settings or unnecessary services can expose an application to attacks.

Recommended mitigation

Apply secure defaults, remove unnecessary services, update software, and review configurations regularly.
